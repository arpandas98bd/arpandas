How to use Root Viewer

  1. Upload a .mat scan (or drag it onto the page). The first analysis takes ~10–30 s; later runs take a few seconds.
  2. Look around: drag to rotate, scroll to zoom, right-drag to pan. Use the view buttons and the Layers panel (tick boxes and opacity sliders). The original MRI has its own contrast sliders.
  3. Tune detection in section 2: lower thresholds find fainter roots but more noise. Hover any setting for an explanation. Press Run analysis.
  4. Correct: double-click a marker, noise speck or water blob, then Mark as root / non-root. Use Erase or Add (top-left of the view) to click away or add bits of root.
  5. Compare: save runs with different settings, then tick Show to overlay them.
  6. Export: traits and per-root tables (CSV), settings (JSON), volumes (MATLAB .mat), RSML architecture, a shareable 3D HTML page and a screenshot, all in one .zip.

Colours: orange = main roots, teal = laterals, purple = detached fragments, blue = water removed, yellow = tips, grey = markers, red = noise, pink = excluded by you, magenta = selection.
