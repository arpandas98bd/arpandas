# Arpan Das portfolio
Static site, no build step. Each page (e.g. education.html) holds its content in the `window.PAGE = {...}` block near the bottom: edit that text.
Add `cv.pdf` and photos in `images/`.
## Publish on GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io` (Public).
2. Upload every file in this folder (Add file > Upload files), keep `images/`.
3. Settings > Pages > Deploy from a branch > `main` / root > Save.
4. Open https://YOUR-USERNAME.github.io after ~1 minute.
